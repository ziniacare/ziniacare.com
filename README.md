# ZiniaCare production website

Public static deployment for https://ziniacare.com/. Built from the approved Next.js, TypeScript and Tailwind CSS homepage using the ZiniaCare brand assets and design tokens.

Hosting: GitHub Pages, with the existing Cloudflare DNS/proxy. This repository contains only the published static output; working source and release records are maintained separately.

Release: 14 October 2026. Original approved copy and headline punctuation retained. The system is in development, not for sale, not CE marked or FDA cleared.

The previous production revision is preserved in Git history. Reverting the production release commit restores the exact preceding site. Board-study and unpublished EMG materials are excluded from this deployment.
